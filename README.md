# Fundamental Physics Sandbox

Interactive simulations and calculators for exploring relativity, fields, and fundamental physics equations.

The idea is to build tools that make equations feel less static. Not just formulas on paper, but things you can move, change, compare, and visualize.

## What this project is for

This repo starts with relativity:

- time dilation at different speeds
- proper time vs observer time
- reference frames
- gravitational time dilation
- black hole distance effects
- age comparison between observers

Later, it can grow into other parts of fundamental physics:

- electromagnetic fields
- Maxwell equations
- wave behavior
- quantum mechanics
- field theory ideas

## Goal

Build small tools to explore physics by changing parameters and seeing what happens.

Calculators, plots, simulations, notes, and whatever helps make the math easier to understand.

## Run the app

Activate the environment:

    conda activate physics_sandbox

Run the app:

    streamlit run apps/relativity_app.py

Open:

    http://localhost:8501
